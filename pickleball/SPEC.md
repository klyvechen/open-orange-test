# 匹克球 2D 模擬遊戲 — 第一版規格

## 目標
單一檔案網頁遊戲 `pickleball.html`（HTML + Canvas + 原生 JavaScript，無外部依賴、無 build step），瀏覽器打開即可玩。

## 範圍（第一版）
- **單打**，玩家 vs 電腦 AI。
- **側視 2D**（橫向看球場：x = 球場長度方向，y = 高度）。網子在中間，有可見高度（中央約 34 英寸）。地面、廚房線（離網 7 英尺）要畫出來。
- 球有**高度**：拋物線飛行、受重力、落地反彈。

## 核心需求：擊球旋轉（最重要）
玩家擊球時可選三種：
1. **直球（平擊 / flat）**：無旋轉，標準拋物線。
2. **正旋（上旋 / topspin）**：飛行中額外向下的力（Magnus 效果），球路較低、下墜快；落地後反彈**較低、向前衝較快**。
3. **逆旋（下旋 / backspin / slice）**：飛行中額外向上的力，球飄較久；落地後反彈**較慢、較高或往回煞**。

- 物理：每幀套用重力 + 簡化 Magnus 力（與旋轉量、速度成正比）+ 少量空氣阻力。落地反彈依旋轉調整水平速度與反彈高度。
- 視覺：球上畫旋轉指示（旋轉的線條或箭頭），並在 HUD 顯示這一拍的球種。可選擇畫淡淡的拖尾。

## 操作（電腦鍵盤）
- ← → 或 A / D：左右移動。
- K：直球；J：正旋；L：逆旋（球在擊球範圍內按下才會擊中）。
- 擊球力道 / 角度可依擊球時機或球的高度簡單決定，不必複雜。
- 空白鍵：發球。

## 回球要考慮來球的旋轉
- 擊球時，來球的旋轉會影響回出去的球：例如回擊正旋來球時，球較容易往上彈飛（出界風險高）；回擊逆旋來球時，球較容易往下掉（掛網風險高）。
- 用同方向旋轉順勢回擊、或用直球硬碰，效果要有差別。玩家和電腦 AI 都適用。

## 第二版（之後再做）
- 新增「困難模式」，與現有的「一般模式」並存，開始畫面可選擇模式；一般模式（K 直球、J 正旋、L 逆旋）完全保留不變。
- 困難模式加入側旋：K 直球、J 左切、L 右切、I 上抽、下抽（按鍵待定）。
- 側旋需要球場寬度方向，純側視看不到左右偏移，要改成俯視或斜視的 2.5D 視角。

## 規則（簡化即可）
- 下手發球，球要過網並落在對方場內。
- 球出界、未過網、兩次落地 → 失分。
- 先到 11 分且領先 2 分獲勝（第一版可簡化為每球得分 rally scoring，請在註解說明）。
- 雙彈跳規則、廚房規則：第一版**可省略**。

## 電腦 AI
- 會移動到預測落點並回擊，隨機選擇三種球種。
- 有簡單的反應延遲與誤差，讓玩家打得贏。

## HUD
- 比分、目前發球方、上一拍球種、得失分原因提示（如「出界」「掛網」）。
- 開始畫面顯示操作說明；比賽結束顯示勝負與「再玩一次」。

## 品質
- 固定時間步長的物理更新（例如 60Hz），畫面跟視窗大小縮放。
- 程式碼結構清楚：物理、AI、繪圖、輸入分開成不同函式或區塊，並加上適量註解。
