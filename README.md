## 專案

### 🏓 匹克球 2D 模擬遊戲（`pickleball/`）

單一檔案的網頁遊戲，下載後用瀏覽器打開即可遊玩，無需安裝任何東西。

**特色**
- 單打：玩家 vs 電腦 AI
- 側視 2D，球有高度：拋物線飛行、重力、落地反彈，網子有實際高度
- 三種擊球，各有不同的飛行軌跡與落地反彈：
  - **直球（平擊）**：無旋轉，標準拋物線
  - **正旋（上旋）**：飛行時下壓、球路低，落地後反彈低、往前衝
  - **逆旋（下旋）**：飛行時上飄、滯空久，落地後反彈慢、往回煞
- 回球會受來球旋轉影響：回擊正旋球容易往上彈飛，回擊逆旋球容易往下掛網

**操作**

| 按鍵 | 動作 |
|---|---|
| ← → / A D | 左右移動 |
| K | 直球 |
| J | 正旋 |
| L | 逆旋 |
| 空白鍵 | 發球 |

**規則（第一版簡化）**
- 下手發球，球要過網並落在對方場內
- 出界、掛網、落地兩次即失分
- 先到 11 分且領先 2 分獲勝
- 雙彈跳規則與廚房（禁止截擊區）規則暫不實作

**如何遊玩**
1. 下載 `pickleball/pickleball.html`
2. 用 Chrome、Edge 或其他瀏覽器打開
