# 遊戲二：匹克球 3D（背後視角）— 第一版規格

## 目標
網頁 3D 匹克球遊戲 `pickleball-3d/index.html`，瀏覽器打開即可玩，部署在 GitHub Pages：
https://klyvechen.github.io/open-orange-test/pickleball-3d/

- 技術：HTML + JavaScript + 3D 繪圖（建議 Three.js，用 ES module 從 CDN 載入，無 build step）。
- 和遊戲一（2D 側視版）是獨立的兩個遊戲，互不影響。

## 視角與畫面
- 鏡頭在玩家**身後略高處**（越肩視角）：畫面最前面是**自己角色的背影**，往前看是**球網**，網子對面是**對手（人形角色）**。
- 鏡頭跟著玩家移動，永遠面向對面場地。
- 3D 球場照真實比例：寬 20 ft、長 44 ft，網高（中央 34 英寸、兩側 36 英寸），畫出底線、邊線、中線、廚房線（離網 7 ft）。
- 球有影子，用來判斷球的高度和落點。

## 移動
- **WASD 或方向鍵**：前、後、左、右移動（在自己的半場內）。
- 球過來時，玩家要先**左右（和前後）移動到球的位置**，再擊球。
- 畫面上可以顯示來球的預測落點提示（一般難度顯示、之後可做成可關閉）。

## 擊球（五種）
| 按鍵 | 球種 | 效果 |
|---|---|---|
| K | 直球 | 無旋轉，標準拋物線 |
| J | 左切（左側旋） | 飛行中往左彎，落地後往左偏彈 |
| L | 右切（右側旋） | 飛行中往右彎，落地後往右偏彈 |
| I | 上抽（上旋） | 球路低、下墜快，落地後反彈低、往前衝 |
| 逗號 , | 下切（下旋） | 飄得久，落地後反彈慢、往回煞 |

（按鍵待 Klyve 確認；左右方向以玩家視角為準。）

- 物理：重力 + 3D Magnus 力（旋轉軸 × 速度）+ 空氣阻力；落地反彈依旋轉調整速度與方向。
- 回球受來球旋轉影響：回擊上旋球容易往上飛出界、回擊下旋球容易掛網、回擊側旋球容易往側邊偏。
- 球上要看得出旋轉方向（旋轉紋路或箭頭），HUD 顯示這一拍的球種。

## 對手
- 電腦 AI，人形角色，會移動到預測落點回擊，五種球種隨機使用。
- 有反應延遲與誤差，讓玩家打得贏。

## 規則（簡化，同遊戲一）
- 單打。下手發球，過網並落在對方場內。
- 出界、掛網、兩次落地即失分。
- 每球得分制，先到 11 分且領先 2 分獲勝。
- 雙彈跳、廚房規則：第一版可省略。

## HUD
- 比分、發球方、上一拍球種、得失分原因（出界、掛網、兩次落地）。
- 開始畫面顯示操作說明，結束畫面顯示勝負與「再玩一次」。
